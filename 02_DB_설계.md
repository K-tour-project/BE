# 02. DB 선택 & 스키마 설계

## A. 어떤 DB를 쓸까 — 결론: **PostgreSQL + PostGIS** (호스팅은 **Supabase** 추천)

### 우리 데이터의 3가지 성격 → 요구사항
1. **작품↔장소 다대다(M:N) 관계** → 조인·관계 무결성이 자연스러운 **관계형 DB** 필요
2. **지도 영역(bbox)·반경 조회** → **공간 인덱스(지오)** 필요
3. **작품명 자동완성·초성검색** → **한글 텍스트 검색** 필요

### 후보 비교
| DB | M:N 관계 | 지오쿼리 | 한글검색 | 평가 |
|---|---|---|---|---|
| **PostgreSQL + PostGIS** | ◎ | ◎ (`ST_DWithin`, `ST_MakeEnvelope`) | ◎ (pg_trgm + 초성컬럼) | **최적** |
| MySQL | ○ | △ (공간기능 약함) | △ | 가능하나 손해 |
| MongoDB | △ (조인 불리) | ○ (2dsphere) | △ | M:N 핵심이라 부적합 |
| Firebase Firestore | △ | △ (복합 지오쿼리 어려움) | △ | 관계형+지오 동시엔 부적합 |

### 왜 Supabase(관리형 Postgres)인가
- Postgres + **PostGIS 확장 기본 지원** + **Auth** + **Storage(포스터/썸네일)** + **자동 REST/GraphQL API**를 한 번에 제공
- 5인 팀·5~9월 개발 일정에 **백엔드 공수 대폭 절감**, 무료 티어로 MVP 충분
- 직접 운영 선호 시: Docker로 `postgis/postgis` 이미지 띄워도 동일 스키마 사용
- (대안: Neon, Railway, AWS RDS+PostGIS 등 — 스키마는 그대로)

## B. 스키마 (PostgreSQL DDL 초안)

```sql
CREATE EXTENSION IF NOT EXISTS postgis;
CREATE EXTENSION IF NOT EXISTS pg_trgm;

-- 작품
CREATE TABLE title (
  id           BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  type         TEXT NOT NULL CHECK (type IN ('movie','drama','show')),
  title_ko     TEXT NOT NULL,
  title_en     TEXT,
  release_year INT,
  poster_url   TEXT,
  synopsis     TEXT,
  genres       TEXT[],
  kmdb_id      TEXT,
  tmdb_id      TEXT,
  era          TEXT,           -- 사극 시대(폴백용)
  keywords     TEXT[],         -- 인물/사건/배경(폴백용)
  chosung      TEXT,           -- 초성검색용(예: 'ㅅㅈ ㅇㄱ ㄸㄹ')
  popularity   INT DEFAULT 0,
  created_at   TIMESTAMPTZ DEFAULT now(),
  updated_at   TIMESTAMPTZ DEFAULT now()
);

-- 장소
CREATE TABLE place (
  id                   BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  name                 TEXT NOT NULL,
  geom                 GEOGRAPHY(Point,4326) NOT NULL,
  address              TEXT,
  area_code            TEXT,
  sigungu_code         TEXT,
  tour_content_id      TEXT,                 -- TourAPI 조인키
  tour_content_type_id INT,
  category             TEXT,
  thumbnail_url        TEXT,
  overview             TEXT,
  tel                  TEXT,
  homepage             TEXT,
  use_time             TEXT,
  rest_date            TEXT,
  source               TEXT,
  tour_synced_at       TIMESTAMPTZ,
  created_at           TIMESTAMPTZ DEFAULT now()
);

-- 작품↔장소 (핵심 자산)
CREATE TABLE title_place (
  id                BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  title_id          BIGINT NOT NULL REFERENCES title(id) ON DELETE CASCADE,
  place_id          BIGINT NOT NULL REFERENCES place(id) ON DELETE CASCADE,
  relation_type     TEXT NOT NULL CHECK (relation_type IN
                      ('filming_site','filming_candidate','background',
                       'historical','fan_spot','nearby_recommend')),
  scene_description TEXT,
  relevance_reason  TEXT,
  confidence        TEXT CHECK (confidence IN ('verified','likely','inferred')),
  source_url        TEXT,
  created_at        TIMESTAMPTZ DEFAULT now(),
  UNIQUE (title_id, place_id)
);

-- 코스
CREATE TABLE course (
  id                BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  user_id           UUID,                    -- 익명 허용(NULL 가능)
  name              TEXT,
  transport_mode    TEXT CHECK (transport_mode IN ('car','transit','walk')),
  start_geom        GEOGRAPHY(Point,4326),
  total_distance_m  INT,
  total_duration_min INT,
  created_at        TIMESTAMPTZ DEFAULT now()
);
CREATE TABLE course_item (
  id                BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  course_id         BIGINT NOT NULL REFERENCES course(id) ON DELETE CASCADE,
  place_id          BIGINT NOT NULL REFERENCES place(id),
  visit_order       INT NOT NULL,
  stay_minutes      INT,
  travel_to_next_min INT
);

-- 지역코드
CREATE TABLE region (
  area_code     TEXT NOT NULL,
  sigungu_code  TEXT,
  name          TEXT NOT NULL,
  parent_name   TEXT,
  PRIMARY KEY (area_code, sigungu_code)
);

-- 인덱스
CREATE INDEX idx_place_geom    ON place USING GIST (geom);          -- 지오쿼리
CREATE INDEX idx_place_content ON place (tour_content_id);
CREATE INDEX idx_title_name    ON title USING GIN (title_ko gin_trgm_ops); -- 부분일치
CREATE INDEX idx_title_chosung ON title USING GIN (chosung gin_trgm_ops);  -- 초성검색
CREATE INDEX idx_tp_title      ON title_place (title_id);
CREATE INDEX idx_tp_place      ON title_place (place_id);
```

## C. 대표 쿼리 패턴
```sql
-- 지도 bbox 내 장소
SELECT * FROM place
WHERE ST_Intersects(geom, ST_MakeEnvelope(:minLng,:minLat,:maxLng,:maxLat,4326)::geography);

-- 반경 N미터 주변 추천
SELECT * FROM place
WHERE ST_DWithin(geom, ST_MakePoint(:lng,:lat)::geography, :radius);

-- 작품의 촬영지 목록
SELECT p.*, tp.relation_type, tp.scene_description
FROM title_place tp JOIN place p ON p.id = tp.place_id
WHERE tp.title_id = :titleId;

-- 자동완성(부분일치+초성)
SELECT * FROM title
WHERE title_ko ILIKE '%'||:q||'%' OR chosung ILIKE '%'||:q||'%'
ORDER BY popularity DESC LIMIT 10;
```
